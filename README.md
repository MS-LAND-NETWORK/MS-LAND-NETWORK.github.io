# MS LAND NETWORK website

Static website built with HTML, CSS and JavaScript for GitHub Pages.

## Publish
1. Upload all files and folders in this project to the root of the `MS-LAND-NETWORK.github.io` repository.
2. In Settings → Pages, choose Deploy from a branch, `main`, and `/ (root)`.
3. Visit `https://MS-LAND-NETWORK.github.io`.

The root `index.html` redirects visitors to `/home/`.
